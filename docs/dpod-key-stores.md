# DPoD key stores

The organisation admins can add their own Thales Luna Cloud HSM (DPoD) partition as a key store. The platform then creates and uses the signing keys of that organisation in its own partition, and the keys cannot leave it. Many organisations can share a group of HSM signers, or an organisation can have a group of its own.

We set up this capability with each customer, based on their requirements. Contact support@igrant.io.
