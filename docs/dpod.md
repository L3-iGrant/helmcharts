# Thales Luna Cloud HSM (DPoD)

The platform can use a partition of Thales Luna Cloud HSM (Thales Data Protection on Demand) instead of an HSM in your data centre. The partition can unseal OpenBao automatically and can keep the local signing keys of the organisations. This gives hardware protection for the keys without HSM hardware of your own.

We set up this capability with each customer, based on their requirements. Contact support@igrant.io.
